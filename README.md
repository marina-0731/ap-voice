# AP(エーピー)- みんなの声

**声が、順番に届く。** 同時に話してもかぶらない、聞くのも読むのも選べるインクルーシブ音声チャット。

## コンセプト

- 発話開始タイミングをサーバーが検知し、**話した順にボイスメッセージが再生される**タイムラグ式通話
- 全発話が自動で文字起こしされ、**聴覚障害のある人は「読む」モード、視覚障害のある人は「聞く」モード**で同じ場に参加できる
- 相槌(0.8秒未満の短い発話)はキューに並ばず文字としてだけ届く

## 構成

```
/(リポジトリ直下 = Render の Root Directory が server を指せる形)
├─ app/              # Expo Router 画面(ホーム / ルーム / 規約 / ブロック一覧)
├─ components/       # QueueVisualizer, TranscriptFeed, TalkButton, ConsentGate
├─ constants/        # 利用規約・プライバシーの本文
├─ hooks/            # useSocketQueue, useRecorder, useQueuePlayer, useModeration
├─ services/         # socket.io クライアント, ブロック/通報, 読み上げ制御, 端末ID
├─ theme/            # デザイントークン(WCAG AA準拠)
└─ server/           # キューイングサーバー(Node.js + socket.io)
```

## 起動方法

### 1. サーバー
```bash
cd server
npm install
npm start          # :3001 で起動
```

### 2. アプリ
```bash
npm install
npx expo start
```

`app.json` の `extra.serverUrl` は本番サーバー(`https://ap-server-896x.onrender.com`)を指しています。
ローカルのサーバーにつなぎたいときだけ、実機から見えるIPに書き換えてください。
例: `"serverUrl": "http://192.168.1.10:3001"`

Expo Go で2台以上の端末から同じルームコードで入室すると、キューイング通話を体験できます。

## STT(文字起こし)

`server/index.js` の `transcribe()` が OpenAI Whisper に接続済み(日本語固定)。
差し替えたいときも、触るのはこの関数だけで完結します。

- APIキーは環境変数 `OPENAI_API_KEY` から読みます(コードには含めない)
- **キーが未設定でもサーバーは起動し、音声通話はそのまま動きます**
  (文字起こしだけが `(文字起こしは現在利用できません)` になる)
- API失敗・タイムアウト(20秒)でも例外を投げず、キューは止まりません
- 文字起こしは**再生の後追い**で届きます。Whisperの往復を待って再生を遅らせないため、
  `speech_end` はまず順番を進め、文字は届き次第あらためて配信します

フィラー除去はフェーズ2(まずは素の精度を確認する)。

## 安全機能(App Store ガイドライン 1.2 対応)

| 要件 | 実装 |
|---|---|
| 通報導線 | 文字起こしの各発言を長押し、または「⋯」ボタン → `POST /report` |
| ブロック | 端末内(`ap:blocked`)。声の再生をスキップし、文字も非表示。即時反映 |
| 利用規約への同意 | 初回起動時の同意画面(`components/ConsentGate.tsx`) |
| 24時間以内の対応表明 | 規約・通報完了ダイアログ・審査メモに明記 |

通報はサーバーのログに `[REPORT]` として残ります。
環境変数 `REPORT_WEBHOOK_URL` を設定すると、その宛先にも転送します。

## アクセシビリティ

- スクリーンリーダー(VoiceOver / TalkBack)が有効なときは、
  「押している間だけ録音」から**タップ式の開始/停止**に自動で切り替わります
  (長押しはスクリーンリーダーに横取りされてアプリに届かないため)。手動切替も可能
- 音声の再生中はスクリーンリーダーへの読み上げを抑制します(`services/announcer.ts`)
- 文字起こしフィードは `accessibilityLiveRegion="polite"` で、読んでいる途中のフォーカスを奪いません
- 話者は色だけでなく名前テキストでも識別できます
- 文字サイズ拡大に備え、入力欄・ボタンは固定 `height` ではなく `minHeight` で組んでいます

## 検証済みのコアロジック

`server/test-queue.mjs` で以下を自動テスト済み:

- ✅ ほぼ同時(0.3秒以内)の発話開始でも、開始が早い方が先に再生される(音声データの到着順に依存しない)
- ✅ キュー先頭が録音中の間は追い越さない(発言順の保証)
- ✅ 全員の再生完了で次のエントリへ進行
- ✅ 短い発話(相槌)はキューをスキップし文字だけ残る
